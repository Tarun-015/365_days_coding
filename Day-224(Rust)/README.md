# Day 01 - Rust Programming Fundamentals

## Overview
This repository contains my Day 1 learning and practical implementation as part of my **30 Days of Rust Challenge**.

The objective of Day 1 is to understand Rust fundamentals, set up the development environment, and write basic programs using Rust syntax.

## Topics Covered

- Introduction to Rust
- Rust installation and environment setup
- Rust compiler (`rustc`) and Cargo
- First Rust program: Hello World
- Variables and mutability
- Constants
- Basic data types:
  - Integers
  - Floating-point numbers
  - Boolean
  - Characters
  - Strings

## Mini Project: Student Information System

A basic command-line application that collects student information and generates a student report.

### Features
- Accepts student name, age, and marks.
- Converts user input into appropriate data types.
- Evaluates whether the student has passed or failed.
- Displays a formatted student report.

### Concepts Applied
- Variables (`let`)
- Mutable variables (`mut`)
- Constants (`const`)
- User input (`std::io`)
- Type conversion (`parse`)
- Conditional expressions (`if/else`)
- String handling

## Key Learnings

1. Rust is a statically typed, compiled programming language.
2. Variables are immutable by default.
3. The `mut` keyword allows variable modification.
4. Rust provides strong compile-time type checking.
5. Cargo simplifies project creation, dependency management, and execution.
6. Rust requires explicit type conversion in situations where numeric types differ.
